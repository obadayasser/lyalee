# 🛍️ Layalee Fashion Shop – E-Commerce Web App for Women's Abayas

Layalee Fashion Shop is a complete e-commerce web application built with **React.js** and **Bootstrap**.  
It’s a modern online store for selling women’s abayas, fully functional with cart management, checkout, and Firebase backend integration.
