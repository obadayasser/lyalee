# 🛍️ Layalee Fashion Shop – E-Commerce Web App for Women's Abayas  

**Layalee Fashion Shop** is a full e-commerce web application specialized in **selling women's abayas**.  
It is designed to provide a smooth online shopping experience with a **modern React.js + Bootstrap frontend** and **Firebase backend integration** for real-time database and authentication.  

---

## ✨ Features  
- 🖼️ **Product Catalog** – Browse products with full details (images, price, description, sizes, and colors).  
- 🛒 **Shopping Cart** –  
  - Add products with quantity, color, weight, and height options.  
  - Update or remove items easily.  
  - Cart persistence using `guestId` (works even without login).  
- 💳 **Checkout Flow** – Seamless order processing.  
- 🔍 **Product Details Page** – Individual product view with zoomable images.  
- 📱 **Responsive Design** – Works on mobile, tablet, and desktop.  
- 🔐 **Authentication (Firebase)** – Login & identity management (extendable).  
- 📊 **Firestore Database** – Products and orders stored in Firebase.  

---

## 🛠️ Tech Stack  
- **React.js** – Frontend framework  
- **Redux Toolkit** – State management (Cart, Checkout, Products)  
- **Bootstrap / React-Bootstrap** – Responsive and modern UI  
- **Firebase** –  
  - Firestore Database – Product & order storage  
  - Authentication – User management (optional)  
  - Hosting – Deployment  
- **React Router** – Page navigation  
- **React Toastify** – Interactive notifications  
- **AOS (Animate On Scroll)** – Smooth animations
